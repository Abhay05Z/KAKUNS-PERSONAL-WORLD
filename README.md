## 🌟 What's Inside This Sanctuary

### 1. **All 49 Photographs — Non-Linear Multi-Manner Presentation (`/#/gallery`)**
- **49 Photos Included**: All 46 original `.webp` photos + the **3 newly added photos** (`.jfif` / `.jpg`) prominently featured with `✨ NEW 🎀` badges!
- **Not in a Sequence**:
  - 🧸 **Scattered Scrapbook & Moodboard**: Organic tilted polaroids (-3.5°, 2.8°, 4.2°), colored washi tapes, paper clips, cute teddy stickers (🧸, 🎀, 💖, 🍓, 🍯, 🥺), and handwritten poetry notes.

  - 🔀 **"Shuffle Photos (Non-Sequence)" Button**: Instant dynamic re-shuffling of photos on the fly so they never appear in a fixed sequence!

### 2. **56 Spoken Poetry Reels & Video Showcase (`/#/poetry`)**
- **All 56 MP4 Videos Integrated**: Short spoken-word reels and aesthetic poetry clips.
- **Poetry on Every Reel**: Each video features a poetic title, couplet in Hindi/Urdu script, and poetic English translation.
- **High-Performance Architecture**: Automatically generated lightweight thumbnail posters for all 56 videos so pages load instantaneously with zero lag.
- **Full Theater / Reel Modal**: Play/pause, loop, mute/unmute audio control, full-screen view, and a *"Send a Teddy Hug & Confetti 🧸💖"* celebration button.
- **Shuffle Reels**: Dedicated non-sequence shuffle button and mood filters (*Soulful*, *Shayari & Nazms*, *Aesthetic Vibe*, *Pookie Sweetness*, *Warm & Comforting*).

## 🛠️ Tech Stack & Media Assets

- **Framework**: React 18 + TypeScript + Vite + Tailwind CSS
- **Media**: 49 Photos (`public/assets/gallery/`), 56 Videos (`public/assets/videos/`), 56 Posters (`public/assets/videos/thumbnails/`)
- **Interactions**: Canvas Confetti, localStorage persistence, keyboard controls, multi-view layout switchers.

## 🚀 Running & Building

| Command | Action |
|---|---|
| `npm run dev` | Starts dev server at `http://localhost:3000` |
| `npm run build` | Compiles production bundle in `dist/` |
| `npm run preview` | Runs production preview server at `http://127.0.0.1:4173` |

> **Production Build**: Verified and compiled with zero errors. All 49 photos, 56 videos, thumbnails, and interactive features are live and functioning.
